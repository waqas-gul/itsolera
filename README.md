- **Service Showcase** (Detailed service breakdowns)
- **Expert Team Profiles** (With skills visualization)

- **Interactive Contact Form** (With backend processing)

- **Responsive Design** (Mobile-optimized)
- **Fast Performance** (90+ Lighthouse score)

## 🛠 Technology Stack

### Frontend
- React.js (Functional Components + Hooks)
- Tailwind CSS (Utility-first styling)
- Framer Motion (Animations)
- React Icons (Comprehensive icon set)
- Axios (HTTP Client)

### Backend
- Node.js (v18+)
- Express.js (REST API)
- MongoDB (Database)
- Mongoose (ODM)
- Nodemailer (Email service)

### DevOps
- Docker (Containerization)
- CI/CD Pipeline
- AWS EC2 (Hosting)
- Cloudflare (CDN & Security)

## 📦 Installation Guide

```bash
# Clone the repository
git clone https://github.com/waqas-gul/itsolera
cd company-website

# Install dependencies
npm install

# Configure environment variables
cp .env.example .env

# Run development server
npm run dev
