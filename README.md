# ITSolera – Software Company Website

This is a modern and fully responsive website developed for **ITSolera**, a professional software company. Built using the **MERN Stack** (MongoDB, Express.js, React.js, Node.js) and styled with **Tailwind CSS**, the website showcases the company's services, expertise, team, and contact information.

## 🚀 Features

- 🏢 Company overview and services
- 👨‍💻 Dedicated team and testimonials section
- 📞 Contact form with backend functionality
- 📱 Fully responsive design for all devices
- ⚡ High performance with clean, optimized code

## 🛠️ Tech Stack

- **MongoDB** – Database
- **Express.js** – Backend framework
- **React.js** – Frontend library
- **Node.js** – Runtime environment
- **Tailwind CSS** – Utility-first CSS framework
